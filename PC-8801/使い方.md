# PC-8801 デジタル8色変換器の使い方

## まずどちらを使うか

通常は **V2 をおすすめ**します。追加した実機風サンプルを画像ごとに均等に扱って解析しており、頻出タイル、多色のグレー表現、近い色のまとまり方が V1 より改善されています。

ただし万能ではありません。細い髪や肌の陰などで、V1 のほうが模様が控えめで合う画像もあります。迷ったら同じ入力で V1 と V2 を一枚ずつ出して比較してください。

|版|起動ファイル|既定の出力名|特徴|
|---|---|---|---|
|V1|`起動_GUI_V1.bat`|`元名_pc8801_v1.png`|手作業で組んだ論理色域とタイルを使う。比較用として残す版。|
|V2|`起動_GUI_V2.bat`|`元名_pc8801_v2.png`|追加資料を画像単位で解析した頻出タイル・多色グレー・色のまとまりを使う。**推奨**。|

## 起動

配布フォルダで、初回だけ次を実行します。

```powershell
python -m pip install -r requirements.txt
```

以後は使いたい版の `起動_GUI_V1.bat` または `起動_GUI_V2.bat` をダブルクリックします。ネットワークやクラウド処理は使いません。

## 基本手順

1. 「選択…」で画像を開くか、左の入力プレビューへ画像ファイルをドラッグ＆ドロップします。
2. 必要なら出力PNGの名前・場所を変更します。
3. パターン方式と各設定を調整して「PC-8801 デジタル8色へ変換」を押します。
4. 「出力フォルダを開く」で保存先を開けます。

プレビューの「変換対象」には、実際に変換に渡す寸法が表示されます。

## 共通設定

|設定|範囲・既定|意味|
|---|---|---|
|仮想ピクセル|1～8、既定2|処理前にこの大きさの格子へ縮小してから拡大します。1は原寸、2は2×2単位の粗さです。|
|入力を横幅640pxへ縮小|オフ|横幅が640pxを超えるときだけ、縦横比を保って幅640pxへ縮小します。縮小後の画像に色調整と変換がかかります。640px以下は拡大しません。|
|主線しきい値|0～120、既定58|暗い画素を黒い主線として抜く基準です。上げるほど黒線の対象が増えます。|
|赤 (R) / 緑 (G) / 青 (B)|0.50～1.50、既定1.00|変換前の各RGB成分の倍率です。1.00が無補正です。|
|彩度|0.00～2.00、既定1.00|0で無彩色、1.00で無補正、上げると色味を強めます。|
|明度|0.50～1.50、既定1.00|変換前の明るさの倍率です。|
|コントラスト|0.50～1.50、既定1.00|中間調から明暗を離す強さです。|
|輪郭抽出|0.00～1.00、既定0.00|明暗境界を追加で黒線にする強さです。セル塗りを締めたいときに少しだけ上げます。|

RGB・彩度・明度・コントラストは、スライダー右側の欄へ数値を直接入力できます。これらと640px縮小の状態は、入力プレビューにリアルタイムで反映され、そのまま変換にも使われます。

## PC-8801 専用設定

|設定|意味|
|---|---|
|PC-8801 200ライン出力|入力画像を先に縦1/2へ縮小して変換し、最後に各走査線を縦へ2回複製します。出力サイズは入力と同じ（640px縮小を有効にした場合は縮小後と同じ）で、縦長のPC-8801ドット比率を再現します。|
|通常4×2|4×2タイルを中心に使います。模様は比較的大きめです。|
|通常4×4|全色を4×4内の16段階で混色します。細かい濃度差を作れます。|
|通常Mix（4×2＋4×4）|4×2を優先し、必要なところだけ4×4を使います。既定で、まず試す方式です。|
|グラデーション|4×4の細かい混色を優先し、空などをなだらかにつなげます。アニメ塗りの境界は弱くなります。|

横一列だけの縞模様は候補から避けています。肌や空が急に別色へ飛ぶときは、主線しきい値より先に「グラデーション」またはRGB・明度を試すのが筋です。
