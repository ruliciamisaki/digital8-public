# PC-9801・4096色中16色変換器の使い方

## まずどちらを使うか

通常は **V2 をおすすめ**します。追加のPC-9801資料を画像単位で均等に解析し、4×4・2色タイルの選び方と近い色のまとまり方を改善しています。

V1は以前の手法を残した比較用です。V2で模様が強すぎる、または画面ごとの癖を比較したい場合だけ試してください。

|版|起動ファイル|既定の出力名|特徴|
|---|---|---|---|
|V1|`起動_GUI_V1.bat`|`元名_pc9801_v1.png`|初期の固定パレット・4×4二色タイル方式。比較用として残す版。|
|V2|`起動_GUI_V2.bat`|`元名_pc9801_v2.png`|追加資料から、複数画像で支持されたタイルを選ぶ。**推奨**。|

## 起動と基本手順

初回だけ、配布フォルダで次を実行します。

```powershell
python -m pip install -r requirements.txt
```

その後、使いたい版の `起動_GUI_V1.bat` または `起動_GUI_V2.bat` をダブルクリックします。画像は「選択…」または入力プレビューへのドラッグ＆ドロップで指定し、変換後は「出力フォルダを開く」で保存先を開けます。ネットワーク・クラウド処理は使いません。

## 固定パレット

「固定パレット」から選ぶ16色だけを出力に使います。選択欄の下には、そのパレットの16色が横一列で表示されます。元画像に近い色が出ないときは、まず別の固定パレットを試してください。

## 共通設定

|設定|範囲・既定|意味|
|---|---|---|
|仮想ピクセル|1～8、既定1|処理前に格子化する粗さです。1は原寸です。|
|入力を横幅640pxへ縮小|オフ|横幅が640pxを超えるときだけ、縦横比を保って幅640pxへ縮小します。以後の色調整・変換は縮小後の画像に対して行います。|
|主線しきい値|0～120、既定58|暗い画素を最も暗い固定パレット色の主線にする基準です。上げるほど主線が増えます。|
|赤 (R) / 緑 (G) / 青 (B)|0.50～1.50、既定1.00|変換前の各RGB成分の倍率です。1.00が無補正です。|
|彩度|0.00～2.00、既定1.00|0で無彩色、1.00で無補正です。|
|明度|0.50～1.50、既定1.00|変換前の明るさの倍率です。|
|コントラスト|0.50～1.50、既定1.00|中間調から明暗を離す強さです。|
|輪郭抽出|0.00～1.00、既定0.00|明暗境界を最も暗い色で追加強調します。|
|塗り判定の安定化|0.00～1.00、既定0.20|近い入力色が隣り合う場所で別々の二色タイルに跳ねないよう、塗りの選択をまとめる強さです。上げすぎると細かな色差が消えます。|

RGB・彩度・明度・コントラストは右側の欄へ直接入力できます。これらと640px縮小の状態は入力プレビューにもリアルタイムで反映されます。

## 透明PNGとアルファマスク

入力PNG・GIF・WebPに透明度がある場合、変換後PNGにもアルファを保持できます。「アルファ処理」は次の2方式です。

|方式|意味|
|---|---|
|そのまま保持（階調あり）|元の完全透明・半透明・不透明をそのまま残す従来方式です。|
|二値化（透明／不透明）|「アルファしきい値」以上を255（不透明）、未満を0（透明）にします。|

「透明マスクも書き出す」は、出力PNGと同じ場所に `出力名_alpha_mask.png` を作ります。マスクは最終的な出力アルファから生成されるRGBグレースケールで、**白が不透明、黒が透明**です。入力に透明度がない場合も、全面白のマスクを作れます。「マスクを白黒反転」を有効にすると、このマスクだけを反転します。出力PNG本体の透明度は反転しません。

## パターン方式

|方式|意味|
|---|---|
|通常セル（4/16刻み）|4×4タイルを4/16刻みで使います。セル塗りを保ちやすい方式です。|
|頻出Mix（資料由来・1/16刻み）|資料から得た4×4二色タイルを使い、1/16刻みの中間濃度を作ります。既定で、まず試す方式です。|
|グラデーション（分散型・1/16刻み）|分散型4×4タイルで1/16刻みの連続調を優先します。空や背景向けで、セル塗りの境界は弱くなります。|
