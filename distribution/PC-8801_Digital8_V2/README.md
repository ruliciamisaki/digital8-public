# PC-8801 Digital 8 Converter V2

追加サンプルを画像単位で重み付けし、4×2・4×4の頻出タイルと多色グレー候補を使う改良版です。通常はこちらをおすすめします。
V1より模様が強く出る画像もあるため、必要なら両方を比較してください。
各スライダーの右側では数値を直接入力できます。R/G/B、彩度、明度、コントラストの調整は、入力プレビューへリアルタイムに反映されます。
「入力を横幅640pxへ縮小」は、幅640pxを超える画像を縦横比を保って縮小してから変換します。変換対象の寸法は入力プレビューの下に表示されます。
縮小処理はPillowのLANCZOSリサンプリングです（Pillow: MIT-CMU License）。

初回だけ、同じフォルダで次を実行します。

```powershell
python -m pip install -r requirements.txt
```

以後は `起動_GUI_V2.bat` をダブルクリックするか、次を実行します。

```powershell
python .\pc8801_gui_v2.py
```
