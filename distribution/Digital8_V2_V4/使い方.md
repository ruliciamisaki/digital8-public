# Digital8 統合版の使い方

ローカル完結のレトロPC風画像変換器です。PC-8801mk2風、PC-9801VM21以降風の画像に変換します。採用方式のV2「頻出パターン式」とV4「2色パターン式」を一つの画面から使えます。[変換例](サンプル.md)も参照してください。

## 準備と起動

WindowsでPython 3.10以上を用意します。初回だけ、このフォルダで次を実行してください。

```powershell
python -m pip install -r requirements.txt
```

以後は`起動_GUI.bat`をダブルクリックするか、次を実行します。

```powershell
python digital8_gui.py
```

## 画像を変換する

アプリの実行画面です。画像をクリックすると拡大して確認できます。

<a href="output_sample/スクリーンショット%202026-10-26%20213641.png"><img src="output_sample/スクリーンショット%202026-10-26%20213641.png" alt="統合コンバーターの実行画面。入力画像と出力PNG、標準プリセット、機種とパレット、方式タブ、保存・プレビューボタンが並ぶ" width="960"></a>

1. 「選択…」から入力画像を開きます。ドラッグ＆ドロップでも指定できます。
2. 「PC-8801標準」または「PC-9801標準」を選びます。必要なら機種、固定パレット、縦長ドットを変更します。
3. 「頻出パターン式」または「2色パターン式」のタブを選び、その方式の設定を調整します。
4. 「プレビュー（保存しない・実寸）」で結果を確認します。別窓の画像は1画像画素を画面上の1座標で表示し、大きい画像はスクロールできます。
5. 「PNGへ変換・保存」を押します。既存の出力PNGまたは透明マスクを置き換える場合は、書き込む前に確認が出ます。キャンセルすると保存しません。

対応する入力はPNG、JPEG、WebP、BMP、GIFです。出力はPNGです。入力プレビューの下には変換時の論理サイズと出力サイズを表示します。

出力先は入力ファイルと同じフォルダに提案され、名前は`元画像名_パレット名.png`になります。たとえばデジタル8色では`image_Digita.png`、Dinsorでは`image_Dinsor.png`です。パレットを切り替えると提案名も更新されます。「保存先…」で場所や名前を変更できます。

## 標準プリセット

| プリセット | パレット | ドット形状 | 方式 |
| --- | --- | --- | --- |
| PC-8801標準 | デジタル8色 | 縦長ドットON | 2色パターン式、市松1:1・交互3:1 |
| PC-9801標準 | パレット01 | 縦長ドットOFF | 頻出パターン式、グラデーション |

両プリセットとも入力の横幅を640pxへ調整し、高さは元の縦横比から計算します。たとえば800×600は640×480です。縦長ドットONでは高さ240の論理画像で色を決め、各行を2回描いて640×480のPNGにします。元画像が640×400なら、PC-8801標準の論理サイズは640×200、出力は640×400です。縦長ドットはPC-9801でも個別にONにできます。

PC-8801のパレットはデジタル8色とDinsorです。Dinsorは512色（RGB各成分3 bit）から選んだ8色です。PC-9801はパレット01～14と「デジタル8色＋半輝度」から選べます。パレット14は4096色（RGB各成分4 bit）へ丸めた版です。

## 調整項目

- 共通設定の「仮想ピクセル」は処理時の画素の大きさ、「主線しきい値」は暗い線を黒として優先する範囲、「輪郭抽出」は線の検出を調整します。
- 赤・緑・青、明度、彩度、コントラストは入力色の補正です。1.00が無補正で、入力プレビューに反映されます。
- 頻出パターン式では機種ごとのパターン候補と「色のまとまり幅」を選べます。PC-9801では「塗り判定の安定化」も使えます。
- 2色パターン式では1:1の市松／縦縞、3:1の交互／片側パターンを選べます。「近い色をまとめる数」を小さくすると、同じタイルを広い範囲で使いやすくなります。
- 透明な入力は「そのまま保持」または「二値化」で扱います。「透明マスクも保存」がONなら`出力名_alpha_mask.png`も保存します。白が不透明、黒が透明です。「マスクを反転」はマスク画像だけを反転します。

## コマンドライン

GUIを使わずに変換する場合は、次のように指定します。

```powershell
python digital8_unified.py input.png output.png --preset pc8801
python digital8_unified.py input.png output.png --preset pc8801 --palette dinsor
python digital8_unified.py input.png output.png --preset pc9801
```

`--help`で全オプションを表示できます。コマンドラインは指定した出力先に直接保存するため、既存ファイルの確認が必要ならGUIから保存してください。
