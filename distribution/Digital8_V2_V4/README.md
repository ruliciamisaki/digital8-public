# Digital8 統合版

ローカル完結のレトロPC風画像変換器です。PC-8801mk2風、PC-9801VM21以降風の画像に変換します。頻出パターン式（V2）/ 2色パターン式（V4）を一つの画面に統合した版です。

[操作手順と設定の説明](使い方.md) / [入力・PC-8801・PC-9801の比較サンプル](サンプル.md)

## 起動

Python 3.10 以上を用意し、このフォルダで次を実行します。

```powershell
python -m pip install -r requirements.txt
python digital8_gui.py
```

`起動_GUI.bat` をダブルクリックしても起動できます。入力画像は選択またはドラッグ＆ドロップで指定します。出力PNGの初期名には選択パレット名が付き、パレットを変更するとファイル名も更新します。保存先に既存のPNGまたは透明マスクがあれば、書き込む前に上書きを確認します。プレビューはPNGを保存せずに変換し、別窓に1:1で表示します。

## プリセット

| プリセット | パレット | ドット | 方式 |
| --- | --- | --- | --- |
| PC-8801標準 | デジタル8色 | 出力高さの半分の論理行で変換し、各行を2回描画 | 2色パターン式、市松と交互3:1 |
| PC-9801標準 | パレット01、16色 | 正方形ドット | 頻出パターン式、グラデーション |

どちらのプリセットも入力の横幅だけを640pxへ調整し、高さは元の縦横比に従って計算します。たとえば800×600は640×480になります。PC-8801ではこの例を論理640×240で変換し、各行を2回描いて640×480で出力します。機種、方式、パレット、縦長ドットは個別に変更できます。PC-8801のパレットにはデジタル8色とDinsorを用意しています。Dinsorは指定色を512色（RGB各3 bit）の最近値へ丸めています。追加の8色アナログパレットは`digital8_unified.py`の`PC88_PALETTES`へ登録できます。

PC-9801のパレットは01～14とデジタル8色＋半輝度を引き継ぎます。パレット14はPC-9801の4096色（RGB各4 bit）の条件に合わせ、提示された色の各成分を0,17,…,255の最近値へ丸めています。

## 設定

「頻出パターン式」の「色のまとまり幅」は、入力の近いRGBを周囲に揃えてから頻出パターンを選びます。PC-9801の「塗り判定の安定化」は、似た入力色の近傍で孤立した塗り選択を補正します。「2色パターン式」の「近い色をまとめる数」は、近い入力色をまとめ、同じ2色タイルを広い面に保つための設定です。両者は処理段階が異なります。

コマンドラインの例:

```powershell
python digital8_unified.py input.png output.png --preset pc8801
python digital8_unified.py input.png output.png --preset pc9801
```

`--machine`、`--method frequent|two_colour`、`--palette`、`--tall-dots` / `--no-tall-dots`、`--resize-640` / `--no-resize-640`、`--colour-groups`、`--fill-stability`なども指定できます。詳細は`python digital8_unified.py --help`を参照してください。
