# Digital8 ブラウザ版

[GitHub Pagesで開く](https://ruliciamisaki.github.io/digital8-public/)

統合版のV2「頻出パターン式」とV4「2色パターン式」をJavaScriptで動かす版です。画像の読み込み、変換、PNG生成はブラウザ内で行います。画像はサーバーへ送信しません。

## 操作

1. 画像を選ぶか、画面にドロップします。
2. PC-8801標準またはPC-9801標準を選び、必要に応じてパレットや変換方式を調整します。
3. 「変換して実寸プレビュー」で結果を確認します。この時点では保存されません。
4. 「PNGを保存」でダウンロードします。ファイル名には選択したパレット名が付きます。既存ファイルの扱いはブラウザのダウンロード設定に従います。

PC-8801標準は8色、縦長ドット、V4の市松・交互です。PC-9801標準はパレット01の16色、正方形ドット、V2のグラデーションです。縦長ドットはPC-9801でも選べます。横幅640pxへの調整時は縦横比を維持します。

ブラウザとPython版で画像の読み込みやリサンプリングの細部が異なる場合があります。サンプル画像で照合し、標準設定の出力色とパターンを確認しています。

## 開発・テスト

`web/`を静的HTTPサーバーで配信してください。実行時にPythonやNode.jsは不要です。

```sh
node --test web/test.mjs
python web/build_data.py
```

`build_data.py`はPython統合版の固定パレットとV2レシピから`converter-data.json`を再生成する開発用スクリプトです。通常は再生成不要です。
